# GroenTech Garantiebeleid

## Servicegarantie
GroenTech biedt 12 maanden servicegarantie op alle geleverde AI-oplossingen.

## Wat valt onder garantie?
- Softwarebugs en technische storingen in onze systemen
- Prestatiegarantie: systemen functioneren zoals overeengekomen in de SLA
- Gratis updates en patches tijdens de garantieperiode

## Wat valt NIET onder garantie?
- Wijzigingen aangebracht door de klant buiten ons advies
- Storingen door derden (cloud providers, internetverbinding)
- Functionaliteit buiten de oorspronkelijke opdracht

## Garantieverzoek indienen
- Via e-mail: support@groentech.nl
- Via het klantportaal: portal.groentech.nl
- Reactietijd bij garantiemelding: binnen 1 werkdag

## Verlengde garantie
Verlengde garantie (tot 36 maanden) is beschikbaar via onze onderhoudscontracten.
Neem contact op met uw accountmanager voor een offerte.
