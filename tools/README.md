# Tools

Python scripts for deterministic execution. Each script does one thing well.

## Conventions
- Scripts read inputs from args or stdin, write outputs to stdout or `.tmp/`
- Secrets come from `.env` via `python-dotenv`
- Scripts are idempotent where possible
- Exit code 0 = success, non-zero = failure with error message to stderr
