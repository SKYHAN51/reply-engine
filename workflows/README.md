# Workflows

Markdown SOPs that define how to accomplish each task in the Newsletters Demo system.

## Structure of a Workflow

Each workflow file covers:
- **Objective** — what success looks like
- **Inputs** — what you need before starting
- **Steps** — ordered sequence of tool calls and decisions
- **Outputs** — what gets produced and where it lands
- **Edge cases** — known failure modes and how to handle them
